# Musterlösung

Hier liegt die vollständige Lösung: alle fünf Aufgaben, alle sieben
Zusatzaufgaben, 240 Tests, und in jedem Vorhersage-Test steht die Vorhersage
als Kommentar über dem Assert.

**Wenn du die Aufgaben gerade bearbeitest, bist du hier falsch.** Bei einer
Vorhersage kostet ein Blick dich die ganze Aufgabe, nicht bloß die Übung.
Zurück zum [Überblick](../exercises/de/00-ueberblick.md).

```
dotnet test solution/AnimalShelter.slnx
```

| Datei | Inhalt |
|---|---|
| `src/AnimalShelter.Core/` | die Implementierung, nach Namespace sortiert |
| `tests/AnimalShelter.Tests/` | 20 Testdateien, dieselbe Struktur |
| [`LINQ.de.md`](LINQ.de.md) | die Antwort auf Aufgabe 5.3, mit gemessenen Zahlen |

Die Kommentare im Code sind ein Teil der Lösung und nicht Beiwerk. Dort steht,
warum eine Entscheidung so gefallen ist und was sie gekostet hat, und an zwei
Stellen steht dort das Ergebnis einer Messung, die der Vermutung widersprach.
